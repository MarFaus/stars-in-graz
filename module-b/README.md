# Stars in Graz

Одностраничный адаптивный сайт однодневного музыкального концерта «Stars in Graz»
(Messe Congress Graz, 30.11.2021). Только HTML и CSS: без JavaScript, сборки и зависимостей.
Переключатель времени в расписании работает на радиокнопках и селекторе `:has()`.

## Настройка разработки

1. Положите папку `mediafiles` от заказчика в корень проекта (рядом с `index.html`).
2. Откройте `index.html` в Chrome или Firefox либо поднимите любой статический сервер,
   например `python3 -m http.server 8080`, и откройте `http://localhost:8080`.
3. Проверка разметки: `java -jar vnu.jar --skip-non-html index.html`.

Структура: `index.html`, стили по разделам в `css/`, шрифты в `assets/fonts/`,
медиа заказчика в `mediafiles/`.

Поддерживаемые браузеры: Google Chrome и Firefox. Проверенные размеры экрана:
360x640, 768x1024 и 1920x1080.
